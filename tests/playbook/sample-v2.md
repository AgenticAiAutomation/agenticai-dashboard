## How does WhatsApp automation work in a clinic?

**Short answer:** a booking triggers a message, a reminder and a token.

Read the [Meta API docs](https://developers.facebook.com/docs/whatsapp) or our [pricing](/pricing).

> **Flow:** Booking made → Confirmation sent → Reminder 24h before
